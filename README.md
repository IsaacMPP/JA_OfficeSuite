# JA OfficeSuite

## Nueva base en evaluación: WordCraft Android

Esta rama prueba el editor [WordCraft Android](https://github.com/artcraft-android/wordcraft-android) en Android con Rust + Kotlin/Compose, mediante un **submódulo fijado a un commit exacto**. Todavía no es una versión terminada de JA OfficeSuite.

**Rama existente conservada:** `feature/android-foundation` (prototipo 0.3.0 que compila).

**Documentación técnica:** [Integración WordCraft Android](docs/WORDCRAFT_ANDROID_INTEGRACION.md).

Compilación de prueba: GitHub Actions > JA OfficeSuite - WordCraft Android integration. Se requiere comprobar su resultado antes de distribuir el APK. La nueva base conserva las licencias y atribuciones del proyecto original.
